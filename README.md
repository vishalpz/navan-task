# navan-task

Take-home B (travel transactions + snapshot invoices). The service lives in [`travel-billing/`](travel-billing/):

```bash
cd travel-billing
./mvnw spring-boot:run   # run the API (needs Java 21 + Docker)
./mvnw test              # run the tests
```

See [travel-billing/README.md](travel-billing/README.md) and [travel-billing/ARCHITECTURE.md](travel-billing/ARCHITECTURE.md).
